Что можно реализовать в Pi?
  • Status: ctx.ui.setStatus('router', text). Не заменяем общий footer.
  • Band: ctx.ui.setWidget('router', component, {placement:'aboveEditor'}); 2–3 строки, ширина в terminal cells.
  • Экран: ctx.ui.custom(), overlay на широком терминале, обычный custom screen на узком. Это временный экран, не постоянная sidebar, сжимающая transcript.
  • Tabs, формы, таблицы и текстовые bars — реализуемые компоненты. Native select/HTML dialog здесь лишь браузерные заместители терминальных списков.
  • Изменения session runtime и preview файлов разделены. В этом HTML ничего не пишется в config, сеть или localStorage.
  • Stats, scope и unknown — честные. Полный ledger сессии и config editor потребуют реализации; текущий debug ring содержит максимум 50 решений.
