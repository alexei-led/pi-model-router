    What is real in Pi

    Monospaced text, theme colors, block bars, keyboard lists and overlays. The surrounding page controls are the prototype lab, not proposed Pi chrome.

    What needs wiring

    The session budget meter needs the existing accumulated-cost counter exposed to the UI snapshot. History charts use retained observations. No new advisor calls or telemetry.

    One entry point

    /router, not /router + /router-ui

    Open the overview in TUI; return concise text elsewhere. Deep links use the same command. Settings stay behind one layer, not four competing dashboards.

    Try /router, /router usage, /router settings, /router status or /router help in the mock input. Escape closes the inspector.
