## Scope and invariants

Native above-editor strip and Now/Routing/Classifier/Usage inspector, session drafts, opt-in Cloudflare choice advisors, retained-history statistics, actual Pi/agterm dev validation and real terminal screenshots. No browser renderer in Pi, persistent config-file editor, session accounting redesign, new routing heuristics, dependency upgrades, private auth inspection, automatic consent, publishing or pushing. Keep router/<profile> stable. Do not alter explicit pin/budget/continuation/abort/fallback semantics. Session drafts apply at the next user-turn boundary; existing commands preserve their documented behavior. Credentials and privacy flags are never UI-editable. Live paid calls require separate bounded approval.

## Ownership and parallelism

| UI worker | ../router-ui-v2-ui | ui.ts, private ui components, UI tests, additive RouterUI types only | focused UI tests + check; durable changed files and API handoff |
| Advisor worker | ../router-ui-v2-advisors | config, choice transport, provider flow, diagnostic state and related tests; no UI/index/commands/docs edits | focused config/advisor/provider/state tests + check; durable diff and configuration contract |

| Fresh reviewers | this worktree after parent handoff | read-only correctness/privacy and UI/validation review | cited findings and parent disposition |

Never two writers in one worktree. Components run concurrently, integration follows both handoffs. Keep main unchanged. Do not import anything from the old execution or touch its state from child agents.
